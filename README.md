
# Network Router Configuration Store

## Project Overview

The Network Router Configuration Store is a Python-based web application that simulates the storage and management of network router configurations.

It uses tuples to store fixed IP addresses and port numbers and dictionaries to map device names to their configurations.

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JSON
- Git and GitHub

## Main Features

- Add router configurations
- Search routers by device name
- Display router configurations
- Prevent duplicate device names
- Validate IPv4 addresses
- Validate port numbers
- Delete router configurations
- Store configurations using JSON

## Data Structures

- Dictionary: Stores device names and configurations.
- Tuple: Stores IP addresses and port numbers.

## How to Run

1. Install Python.
2. Create a virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Start the application:

   python app.py

5. Open http://127.0.0.1:5000 in your browser.

## Project Purpose

This is an academic simulation of router configuration storage. It does not directly configure physical networking hardware.
